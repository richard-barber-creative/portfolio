Admin sign in

This site has no separate admin password — signing in with a GitHub access token is the login, and it's also what lets you save changes. There's no app to install or account to set up beyond your existing GitHub account.

Open GitHub to create my token →

This opens a GitHub page with everything already filled in. Just scroll to the bottom and click the green Generate token button, then copy the token it shows you (you'll only see it once) and paste it below.
